# Learn With Me - Serbian AI Tutor

Serbian language learning content for English-speaking expats moving to Serbia or Montenegro.

## Structure

- **`markdown/`** - Source content in Markdown format (Version 2 - Clean)
- **`website/`** - Static HTML website (Version 1)

## Module 1: Ankommen (Arrival)

### Units

1. **At the Train Station** - biti (to be), zvati se (to be called)
2. **At the Konoba** - hteti (to want), Numbers 1-10
3. **At the Bank** - trebati (to need), Numbers 11-100
4. **Finding a Place to Stay** - Prepositions, Adjectives
